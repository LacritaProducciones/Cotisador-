# NaviWeb — Cotizador Web

Cotizador de páginas web en soles (PEN). Sin internet, sin servidores: HTML + CSS + JS puro.

## Cómo abrirlo
Haz doble clic en `index.html`.

## Probar el ejemplo del restaurante
Al abrir por primera vez ya aparece cargado. Si no, pulsa **Cargar ejemplo restaurante** en el Cotizador. Verás el plan sugerido (Negocio Profesional, por tener 2 páginas y carta), el precio recomendado, mínimo y alto, y el QR como regalo (su valor se muestra pero no se suma). Pulsa **Guardar proyecto**, luego ve a **Presupuesto** para copiar, imprimir o guardar como PDF (diálogo de impresión → "Guardar como PDF").

## Secciones
- **Cotizador**: datos, funcionalidades (marcar y/o regalar) y resultado en vivo con explicación.
- **Proyectos**: buscar, filtrar, ordenar, editar, duplicar, eliminar (con confirmación), exportar/importar JSON validado.
- **Presupuesto**: documento editable listo para imprimir.
- **Ajustes**: planes, tarifa, precios de funciones, QR, hosting/dominio/mantenimiento, colores, restaurar valores.

Los datos se guardan en `localStorage` de tu navegador. Haz copias con *Exportar JSON*. Todos los precios son estimaciones iniciales editables.
